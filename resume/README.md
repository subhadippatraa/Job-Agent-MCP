# Resume Directory

Place your resume PDF here as `master_resume.pdf`.

The system will:

1. Extract text from the PDF
2. Build a skill→evidence mapping
3. Use evidence during job matching

## Supported Formats

- PDF (primary, recommended)

## Important

- Your resume is the source of truth — the system never invents experience
- Resume text is cached locally after first parse
- The resume is NOT sent to external APIs unless you explicitly configure LLM analysis
